## ✨ Features

⚡ **Quick Presets** - 10s, 30s, 60s, 5min buttons  
⏱️ **Custom Timer** - Set 1-3600 seconds  
🔔 **Notifications** - Desktop alerts on completion  
🔊 **Audio Alerts** - Triple beep sound  
⏸️ **Pause/Resume** - Full control  
📊 **Progress Ring** - Animated SVG indicator  
🎨 **Glassmorphism** - Premium design  
📱 **Responsive** - All devices  

## 🚀 How to Run

**Quick Start:**
```bash
# Just open the file
open index.html

# Or double-click index.html in your file explorer
```

**Using Live Server (VS Code):**
1. Install "Live Server" extension
2. Right-click `index.html` → "Open with Live Server"

**Using Python:**
```bash
python -m http.server 8000
# Open http://localhost:8000
```

## 🎯 Usage

1. Click preset buttons (10s, 30s, 60s, 5m) or enter custom seconds
2. Click **START TIMER** button
3. Allow notifications when prompted
4. Pause/Resume/Reset as needed
5. Get notified with sound when done!
